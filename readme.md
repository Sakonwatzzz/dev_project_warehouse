# Warehouse Management System

A simple and efficient warehouse management system built with PHP and MySQL.  
This system includes features such as product tracking, lot control, and stock adjustment.

## 📁 Features

- Product and Lot Management
- Stock In/Out Tracking
- Sales and Inventory Overview
- User-friendly Interface (Tailwind CSS)

## 🛠️ Technologies Used

- PHP (Vanilla PHP, no framework)
- MySQL (Managed via Navicat)
- HTML/CSS (Tailwind CSS)
- JavaScript (for UI interactions)
